<h2>质量分四个维度，缺一个都不完整</h2>
<p>评价一条住宅 IP 好不好，不能只看「是不是住宅」。完整的评价要覆盖四个维度：归属是否准确、网络类型是否真实、稳定性是否够、以及纯净度是否达标。</p>
<p>四个维度对应四种不同的检查方法，也对应四种不同的风险。只看其中一个，很容易出现「这条地址明明是住宅，但用起来一直出问题」的困惑。</p>

<h2>维度一：归属准确性</h2>
<p>指注册地、运营商、物理位置三者是否一致。一致的叫原生，不一致的是拼接资源。</p>
<p>怎么查：查 ASN 与运营商名称，再测延迟推断物理位置。三者吻合才算准确。这一项决定了地址在平台眼里的「可信度」。</p>

<h2>维度二：网络类型真实性</h2>
<p>指它是不是真的家庭宽带出口，而不是机房托管后标注成住宅。</p>
<p>怎么查：看 ASN 是否指向宽带运营商，看延迟量级是否符合跨洲距离，看晚高峰是否有明显波动。三项结合，基本能判断真实类型。</p>

<h2>维度三：稳定性</h2>
<p>指地址会不会变、连接会不会断、延迟会不会飘。这一项要靠时间观察，短时间测不出来。</p>
<p>怎么查：连续七天记录出口地址，同时开一个定时检测看断连。一周之后，变更次数和断连次数就能说明问题。</p>

<h2>维度四：纯净度</h2>
<p>指这条地址的历史是否干净、有没有被大量滥用、同段是否被污染。</p>
<p>怎么查：查黑名单与风险评分，抽查同段邻近地址，再用目标平台做一次低风险操作看反馈。三项结合，能判断它能不能承载账号。</p>

<h2>为什么「住宅」这一项不能代表质量</h2>
<p>因为住宅是一个属性分类，不是质量等级。同样标注住宅的两条地址，一条可能原生独享、历史干净；另一条可能拼接共享、刚被滥用过。</p>
<p>所以看到「住宅」两个字，只说明它通过了第一层筛选。剩下的三个维度，必须自己查。</p>

<h2>质量评分怎么用</h2>
<p>四个维度各给一个简单判断：好、一般、差。四项都好的，可以做核心账号；有两项一般的，做辅助账号；有任何一项差的，别用于账号运营。</p>
<p>这个评分不精确，但它能防止「凭感觉下单」。有框架的判断，永远比没有框架的直觉稳定。</p>

<h2>购买时怎么快速判断</h2>
<p>三步：问 ASN 与承载方式，看对方回答是否具体；买最小量测延迟与晚高峰；连续三天记录地址是否变化。</p>
<p>三步做完大约四天。这四天能筛掉大部分不合格的资源，比买完再发现问题划算得多。</p>

<h2>把判断结论写下来，避免凭印象换资源</h2>
<p>看过归属、类型、稳定性和纯净度四项之后，建议给每条资源记一行结论：归属是否对得上、类型是否真实、晚高峰掉不掉、有没有不良记录。这行字看着简单，但它能避免后续反复试错——下次续费或换供应商时，你有一份自己的对照表，而不是凭「上次那家好像还行」的印象做决定。</p>
<h2>常见问题</h2>
<h3>价格高的质量一定好吗</h3>
<p>不一定。价格反映稀缺度，质量要看四个维度。贵在资源和条款上才值得。</p>
<h3>只看评分够不够</h3>
<p>不够。评分是第三方判断，平台的实际反馈更准。两者结合看。</p>
<h3>为什么同批地址质量不一样</h3>
<p>正常现象。不同地址落在不同城域网、不同接入方式，天然有差异。分配时区分使用即可。</p>
<h3>质量变差了怎么办</h3>
<p>先查原因：是地址变了、还是被牵连、还是自己的使用方式变了。原因不同，处置不同。</p>
